# Model-facing search References (superseded)

Date: 2026-10-20

The earlier compact-hash reference experiment is superseded by
[OpenAI citation markers](2026-10-20-openai-citation-markers.md).
The current implementation exclusively uses OpenAI citation-formatting markers
and per-invocation `turnNurlI` references. No old marker compatibility is retained.
Canonical SHA-256 identities, typed provenance, explicit Unicode code-point
ranges, and automatic capability negotiation remain unchanged.
